# 本轮经验

2026-11-06，书房 TV 云盘与阅读体验集成。

1. **合并关系和交互验证分别检查。** 分支名相似不代表内容重复；先看祖先和工作区状态，保存独立提交后合入最新 main。无文本冲突仍可能留下共享页面的产品遗漏。
2. **排版只用一份规则。** ReadingStyle 同时供阅读器和全局设置使用。本书覆盖与全局默认分别持久化，避免设置页改了默认却悄悄覆盖一本书。
3. **选中状态与焦点分开。** 当前值用琥珀标记，遥控器焦点用浅色边框；重建页面用稳定的书籍/收藏/设置 ID 恢复，不能依赖控件序号。立即滚动可避免小屏当前项暂时只露出一半。
4. **原文位置比页码稳定。** EPUB 章节、UTF-16 文字位置、TXT 段首字节是持久锚点；调字号、栏宽和纸色不重写这些位置。Unicode 代理对、异步迟到回调、跨段保存均需覆盖。
5. **系统控件必须按真实 Android 行为验证。** AlertDialog 的 message 与 list 默认互斥；长摘录需要受限预览和独立备注区域。网页原型不会暴露这类原生问题。
6. **暂停原因分别保存。** 自动翻页的菜单暂停可以自动恢复；手动暂停、手动翻页、应用后台和朗读互斥有不同恢复条件。只用一个布尔值容易意外继续。
7. **功能入口要全局复查。** 阅读器已有栏宽和新功能，不代表设置、关于、指南都同步了。发布前同时检查版本号、默认值范围、首次启动与空状态。
8. **设计、JVM 与设备证据各有边界。** OpenDesign 确认结构和视觉；Robolectric 检查原生布局和边界；实际电视才验证系统服务、Binder、文件选择器和真实遥控事件。缺少中文 TTS 引擎必须写成环境限制。
9. **发布身份和签名按所有权核对。** spudhero 仓库使用对应作者、提交者和 GitHub 账号；开发机默认 debug 密钥可能与已发布 APK 不同，覆盖安装前核对证书，保留历史文件。
10. **能解析 Intent 不代表具备系统能力。** Sony 的 OPEN/CREATE_DOCUMENT 指向电视占位组件，会直接返回。只识别已知占位包；查找结果为空时仍尝试原流程，避免包可见性导致误判。导出缺少界面时不创建快照，保留收藏并解释恢复办法。
11. **主题封装也要保留状态和回调。** 原生 `setTitle()` 不会更新自定义标题，进度须走统一更新入口；表单若覆盖对话框的 OnShow 监听，会丢掉通用样式。先显示再绑定按钮校验，并给自定义内容和列表相同高度上限。
12. **断网验收要真正停止服务。** 在线 TXT 的 48 KiB Range、下载前只有指南、下载后字节/哈希匹配、关闭服务后原文位置和冷启动恢复共同证明存储规则。只看到“离线”标签或小 EPUB 一次读取完都不足以下结论。
13. **自动行为用位置序列验证。** 5 秒间隔下记录运行、开菜单、关菜单、手动暂停的 offset，比肉眼看截图更可靠；本次分别得到推进、保持、恢复、保持，符合用户选择的暂停策略。
14. **连接可用与共享可用是两个状态。** SMBJ 连接仍报告 connected 时，共享可能已因空闲超时关闭；无 cause 的运行时异常因此不能只看 cause 分类。精确结合异常类型和共享状态，仍只重连一次，保留身份错误与文件变更检查。
15. **打开成功、正文可见、实际可读分别验收。** 漫画的 ZIP/目录能加载不代表图片能显示；竖版 PDF 整页渲染正确也不代表电视上小字易读。真实长元数据还能暴露短测试标题没有覆盖的裁切。
16. **警告不能改写原文。** 章节是否含图片的标记与正文分开，让界面解释限制并保留文字锚点。漫画章节末尾也可能有少量文字，不能只判断“纯图片”；测试连续翻过纯图片、图文混排与纯文字，确认提示持续、撤销且焦点恢复。
