## 关键覆盖

- 排版：字号 / 栏宽重排后保留 UTF-16 原文锚点；全局与本书设置隔离；旧书库重载与历史兼容。
- 搜索：大小写、Unicode 代理对、空查询、200 条上限、历史去重、定位高亮及回到搜索前位置；仅使用已加载文本。
- 书库：置顶稳定排序、分组与状态迁移、保存失败回滚；归类不移动源文件。
- 朗读：长段切分、词范围恢复、迟到回调、引擎初始化 / 关闭、中文不可用、音频焦点拒绝和丢失、媒体键、前后台、深度休眠后的定时停止。
- 收藏：遥控器选段、长段与 Unicode、摘录去重、备注更新、原文变化核对、旧书签兼容、4 MiB 元数据边界与失败回滚；导出内容及实际系统文档 URI 写入。
- 自动翻页：菜单暂挂与手动暂停分别管理；手动翻页后不自动恢复；后台停止推进、跨 TXT 片段、异步加载时不写入旧偏移、末尾与退出取消、与其他模式互斥。
- UI：真实 Android View 渲染、设置焦点恢复、480p 控件完整滚入可见区、长标题状态行、暖纸色小字对比度、长摘录不挤掉备注，以及长备注预览与原生操作列表能同时显示。
- 原有 HTTP Range、离线下载、四家网盘协议、会话存储和来源流程测试一并通过。
