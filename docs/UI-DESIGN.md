# 网盘界面优化与原生落地

本轮使用 OpenDesign Cloud，通过 Local Codex 对现有“暗色书房”网盘流程进行重设计。完整交互原型、所需静态资源及原始尺寸规范保存在 [design](../design/README.md)，不打包进入 APK。网页原型使用演示账号和合成二维码；应用继续连接真实协议实现。

## 已落地的变化

| 界面 | Android 原生实现 |
| --- | --- |
| 书籍来源 | 四张整卡可聚焦网盘入口；已连接卡进入账号管理；常用文件夹整行打开，右侧独立管理；本地/USB、SMB、WebDAV 使用紧凑入口 |
| 扫码登录 | 统一深色弹窗、步骤提示、白底二维码和固定状态区；刷新/取消集中排列；等待、已扫码、过期与错误使用明确文字，UC 指明 UC 浏览器 |
| 选择文件夹 | 账号与步骤、固定路径区、可聚焦文件夹行、固定底部确认区；虚拟根位置不能保存；空目录仍可选择；点路径可核对完整名称 |
| 浏览来源 | 在线来源提示、固定路径区、文件夹/书籍图形、类型与已知大小；选书后在线打开为琥珀主操作，离线保存独立说明存储占用 |
| 管理菜单 | 添加多个文件夹、重新扫码/连接另一账号、退出账号、查看已保存位置与移除来源；破坏性操作有明确确认 |

目录 ID 与分页游标继续使用原协议模型，只把可读名称写入展示路径。保存来源仅保存账号、文件夹位置和名称，不触发文件解析或下载。目录加载成功后才提交导航位置；失败保留原页面。返回父目录和刷新当前目录会恢复之前的文件夹/书籍焦点，关闭扫码停止轮询并拒绝旧请求回调。

## 设计映射

沿用背景 `#191c1b`、表面 `#242825`、正文 `#f0eee6`、辅助文字 `#b7bdb4`、琥珀 `#d8b377` 和焦点 `#f8e2b6`。来源列表采用细分隔线，焦点使用明亮边框和提升表面。文字与图形同时表达状态，不依赖颜色。

原生版本保留五项完整侧栏，沿用 146dp 宽度。扫码弹窗首选 744dp、二维码纸面 232dp；较小窗口按可用宽度收缩。常规目录行 52dp、书籍行 62dp，为中文双行信息和原生字体留出空间。阅读方式面板为 620dp。焦点采用原生边框和轻微提升，不对整行缩放，以避免裁切或布局移动。

当逻辑高度低于 450dp 时缩紧页边距与页头、步骤改为紧凑提示、二维码纸面为 180dp；目录确认区仍固定显示，账号选项在弹窗内滚动。长路径可打开详情，字体放大时弹窗也可滚动。以上为 dp/sp 逻辑尺寸，不按物理分辨率硬编码密度。

本轮保留既有原生阅读器、书签、EPUB/TXT/PDF 解析与网盘协议。原型里的页签、模拟状态、DOM 焦点算法、iframe 和演示文件均没有进入应用。
