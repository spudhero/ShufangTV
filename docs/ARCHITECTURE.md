# 架构与存储规则

## 模块

`core` 是不依赖 Android 的 EPUB / TXT 解析器、Kindle 目录拆章与文档视口几何模型；EPUB 元数据检查与正文加载分开。`app` 提供原生 TV 界面、图文分页、私有书库、凭据存储、网络来源、系统 PDF 渲染，以及通过 JNI 接入的独立 libmobi 共享库。

来源适配器统一实现 `NetworkLibrary` 的列目录、打开随机读文件与显式下载三个动作。`RemoteFile` 只暴露长度、按位置读取和关闭，防止在线层意外把流拷贝到磁盘。

`CloudLibrary` 注册阿里、百度、夸克和 UC 的独立 `CloudProvider`，提供二维码申请/轮询、目录分页和原文件直链。网盘账号与 `SourceConfig` 中的书籍文件夹分离，目录/文件 ID 按不透明标识传递，不交给 SMB/WebDAV 路径规范化。文件夹浏览的路径与父栈只在异步加载成功后提交。

## 在线读取

- SMB：保持 SMB2/3 文件句柄，按偏移读取；可恢复的传输中断重建一次连接，核对长度与修改时间，认证失败不盲目重试。
- WebDAV：PROPFIND 列目录，HEAD / 单字节 Range 探测长度，后续逐次验证 206、Content-Range、响应长度与可用对象标识。单次最多 256 KiB；不接受整本 200 响应作为分段内容。
- 网盘：`CloudRangeFile` 先请求单字节范围，再按需读取，每次最多 256 KiB。地址过期或 401/403 最多重新解析一次；校验长度、Content-Range、对象身份与 ETag。错误响应先取消网络请求，避免 HTTP 库为复用连接而排空整本响应。关闭书籍可取消正在读取的请求。
- EPUB：`RemoteChannel` 将随机读取映射为 64 KiB 内存块，最多 16 块；`RemoteZipArchive` 惰性读取 ZIP 内容项，不遍历所有章节的本地头。中央目录限制 2 MiB / 16,000 项，章节正文解压限制 8 MiB，图片输入限制 16 MiB。
- AZW3 / MOBI / AZW / PRC：`MobiArchive` 通过 libmobi 在内存重建正文、资源与虚拟 OPF，再复用 EPUB 的 BookArchive 和阅读模型。所选文件最多 64 MiB，解压正文最多 32 MiB，重建内容总计最多 128 MiB / 16,000 项；旧 MOBI 的单 HTML 根据目录锚点拆成可跳转章节。不会生成中间转换书籍或离线副本；加密内容明确拒绝。资源数据可能借用原始记录缓冲区，因此 native handle 同时持有 MOBIData 和 MOBIRawml，关闭时先释放重建内容，再释放原始记录。
- TXT：`TextSegments` 按最多 48 KiB 读取，通过解码器保留完整字符边界；有限的内存检查点支持返回上一段。
- PDF：`StorageManager.openProxyFileDescriptor` 把系统渲染器的 seek/read 交给远端文件；Kindle 在线解析同样经代理文件描述符读取所选文件。`DocumentViewport` 以屏宽作为 100%，保存归一化平移，`PdfRenderer` 只绘制当前视口，输出限制 3840×2160。关闭书籍时释放文件描述符、网络句柄、章节缓存与位图。

在线模式不创建离线书籍文件、不保存正文或原图磁盘缓存。书架另存有上限的私有封面缩略图，见下文。文件读取失败必须留在在线错误状态；重试仍为同一模式。

## 离线读取

只有用户确认“保存到本地”后，`download` 才创建临时文件。下载有大小上限、空间检查、进度与取消，成功后原子更名，再更新书库中的离线状态。失败或取消清理临时文件。

系统文件选择器提供的本地 / USB URI 以持久授权打开，不复制到应用目录。移除书库记录不删除这些原文件。删除应用保存的离线副本会保留来源、进度和书签。

## 私有数据

`files/library.json` 通过 `AtomicFile` 保存书库与书签。损坏记录禁止覆盖；在线条目只记录书籍身份、来源引用和逻辑位置。`files/books/` 仅包含明确保存的离线副本或用户主动打开的原创使用指南。

来源地址和凭据统一经 Android Keystore AES-GCM 加密后写入私有偏好；关闭应用云备份和设备传输，避免无法迁移的密钥与密文脱节。网络日志不输出口令。

`CloudAccountStore` 独立加密会话、令牌与 Cookie，保留 Cookie 的域、路径、过期、Secure、HostOnly 属性。Cookie 按实际请求 URL 匹配；跨源文件重定向不携带认证头。直链与二维码只保留在内存。账号使用提供商前缀，避免相同数字 ID 覆盖其他网盘账号。迟到的请求只允许更新原会话，不能恢复已退出的账号或覆盖新扫码会话。

## UI 与进度

采用原生 View、焦点描边和方向键，不内嵌网页。异步 I/O 使用串行工作队列，UI 更新检查操作代次；过期结果关闭资源。首次布局在正文加载前不能覆盖已保存偏移。

`CoverRepository` 使用独立串行队列，仅为可见的首页 / 书库封面请求数据；同一身份请求合并，完成时只更新仍挂载的 CoverView，不重建页面或移动焦点。缓存键包含书籍 ID、格式、来源、路径、URI 和已知大小，应用内文件另计长度与修改时间。位图最长 384×576、内存 LRU 8 MiB；`cache/covers-v1` 通过 AtomicFile 写入 PNG，最多 64 MiB / 256 张，可由系统回收。失败不写空缓存，30 秒后重新进入页面可重试。TXT 或无法提取的封面保留生成样式。

EPUB 按 EPUB 3 cover-image、EPUB 2 meta、guide 封面页及已命名封面识别；没有标记时只检查第一个 spine 页的图片，不扫描全书。XHTML / SVG 中的资源仍限制在当前书籍内。Kindle 封面通过 PalmDB 记录表、MOBI / EXTH 偏移单独随机读取，不启动 libmobi 正文重建。PDF 缩略图独立渲染完整第一页，不使用读者当前视口或修改进度。IllustrationDecoder 的全局锁仅保护 AndroidSVG 的全局资源解析器，普通位图网络读取互不阻塞。

文本保存章节索引与 UTF-16 字符偏移，TXT 同时保存段首字节位置。字号、行距变化只触发重排，不保存显示页码作为进度。章节中的 Illustration 记录资源路径、替代文字和文字锚点，保留常见旧图片占位锚点的兼容；PagedTextView 按原文顺序交替显示文本屏和图片屏。

IllustrationDecoder 在工作队列中读取当前图片，光栅图采样到最多约 6 百万像素，SVG 使用 AndroidSVG 并把外部解析限制在当前书籍资源。只持有当前位图，翻走、退出或过期回调都会释放。普通插图自动完整适配，密集图片章节自动屏宽适配；本书设置可覆盖为整图或屏宽。图片纵向位置与适配偏好持久化，跨章清除旧图片偏移。

PDF 保存从零开始的页索引、缩放倍数和归一化 x/y；书签也保留 PDF 与图片的纵向位置。旧 JSON 缺省值为 100% 和零偏移，读入时限制非有限值与越界。默认 PDF 隐藏文字阅读页栏并占满屏幕，上下移动视口；100% 左右翻页，放大后左右平移。

## 独立语音

`ReaderSpeech` 保留 Narration、音频焦点、媒体键、前台与定时语义，通过 `SpeechEngine` 选择离线、Azure 或系统适配器。离线默认启用；浏览或保存网络配置不改变当前选择，不做自动网络回退。

`PcmSpeechEngine` 用独立的串行合成 / 播放队列，最多预取两个短句。短句保存原文 UTF-16 范围，先用 16 字再用 36 字限制首音等待。AudioTrack 播放指针实际前进后才更新高亮，排空已提交样本后才结束段落；取消令牌使旧音频与迟到回调失效。原生句子合成不能中途打断，因此释放 native handle 必须排在该合成任务之后，结果取消后直接丢弃。

`VoicePackManager` 为应用级下载任务；界面关闭不取消下载。固定归档整包及逐文件 SHA-256 校验、受限解压和原子目录替换后才写入完成状态；启动核对文件完整性，加载 JNI 前重新计算全部文件哈希。`files/speech/aishell3-zh-1` 是明确下载的语音资源（31.2 MiB），不含书籍。下载临时包约 30.1 MiB，未用的 172 MiB rule.far 不落盘。正在朗读的租约阻止删除和重装。

Azure 仅请求由地区组成的官方 HTTPS 端点，不携带密钥跟随重定向。地区、音色、密钥通过独立 Android Keystore AES-GCM 密文保存；正文和 24 kHz PCM 仅存在受限内存中。首次选用和试听均明确说明外发内容与费用。离线模型仅支持中文，PDF / 纯图片不新增 OCR。
