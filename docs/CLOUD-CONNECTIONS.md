# 网盘连接与验收

`0.2.0-alpha.1` 增加阿里云盘、百度网盘、夸克、UC 的自有连接器。流程是 **扫码登录 → 选择文件夹 → 添加书籍来源 → 在线打开书籍**，不依赖 CloudDrive2、WebDAV 网关或第三方授权中转。

## 使用

1. 打开“书籍来源”，选择对应网盘。
2. 使用手机应用的“扫一扫”，并在手机上确认。UC 使用 **UC 浏览器**，夸克使用夸克应用。二维码过期后选择“刷新二维码”；返回或取消后不再继续轮询。
3. 登录完成后进入文件夹。阿里云盘先选择资源库或备份盘，再进入书籍目录。选择页同时显示子文件夹和支持的书籍，不只显示目录；有多页时使用“下一页内容”。底部“使用并浏览书籍”添加来源后直接进入该目录，也可选择书籍，添加或复用当前文件夹后进入阅读方式面板。
4. 来源和选择页均展示 EPUB、AZW3、MOBI、TXT、PDF（同族入口兼容 AZW/PRC）。选择“在线打开”时按格式读取所需数据，Kindle 需在内存重建所选文件的压缩记录；需要离线时另选“保存到本地”。选择来源、浏览目录和打开阅读方式面板不会下载文件夹中的书；MP3 等非书籍文件不作为可读书籍显示。

同一账号可以添加多个书籍文件夹。已连接网盘卡进入管理菜单，也可在“书籍文件夹”旁选择“添加文件夹”；选中路径可查看完整位置。移除来源保留已保存的本地书；退出账号后，在线来源需要重新扫码，本地书仍可离线打开。再次登录同一账号可恢复其原有来源引用。

## 会话与错误

- 账号会话使用设备 Android Keystore 加密保存；二维码、短期读取地址只保留在内存。来源记录不包含 Cookie 或令牌。
- 阿里令牌支持续期；百度、夸克和 UC 的会话由首方 Cookie 管理。无法继续使用时明确要求重新扫码。
- 网盘要求额外验证、会员权限或拒绝请求时会报错，不绕过限制。
- 不支持 Range 或原文件发生变化时，在线读取停止，不自动创建离线文件。用户可自行选择是否保存离线副本，当前上限为 128 MiB。
