# 网盘连接与验收

`0.2.0-alpha.1` 增加阿里云盘、百度网盘、夸克、UC 的自有连接器。流程是 **扫码登录 → 选择文件夹 → 添加书籍来源 → 在线打开书籍**，不依赖 CloudDrive2、WebDAV 网关或第三方授权中转。

## 使用

1. 打开“书籍来源”，选择对应网盘。
2. 使用手机应用的“扫一扫”，并在手机上确认。UC 使用 **UC 浏览器**，夸克使用夸克应用。二维码过期后选择“刷新二维码”；返回或取消后不再继续轮询。
3. 登录完成后进入文件夹。阿里云盘先选择资源库或备份盘，再进入书籍目录。选择底部固定的“使用此文件夹”。目录有多页时使用“下一页文件夹”。
4. 在已保存的来源中浏览 EPUB、TXT、PDF。选择“在线打开”时只按需读取；需要离线时另选“保存到本地”。选择来源和浏览目录不会下载文件夹中的书。

同一账号可以添加多个书籍文件夹。已连接网盘卡进入管理菜单，也可在“书籍文件夹”旁选择“添加文件夹”；选中路径可查看完整位置。移除来源保留已保存的本地书；退出账号后，在线来源需要重新扫码，本地书仍可离线打开。再次登录同一账号可恢复其原有来源引用。

## 会话与错误

- 账号会话使用设备 Android Keystore 加密保存；二维码、短期读取地址只保留在内存。来源记录不包含 Cookie 或令牌。
- 阿里令牌支持续期；百度、夸克和 UC 的会话由首方 Cookie 管理。无法继续使用时明确要求重新扫码。
- 网盘要求额外验证、会员权限或拒绝请求时会报错，不绕过限制。
- 不支持 Range 或原文件发生变化时，在线读取停止，不自动创建离线文件。用户可自行选择是否保存离线副本，当前上限为 128 MiB。

## 验证范围

| 网盘 | 已实现的路径 | 无账号在线核对 | 仍需真实账号验收 |
| --- | --- | --- | --- |
| 阿里云盘 | 首方扫码、令牌续期、自有设备签名、两类盘、目录与原文件直链 | 二维码生成、POST 轮询返回 NEW | 扫码确认、设备会话、目录、续期、三种格式读取 |
| 百度网盘 | 首方扫码、Cookie 交换、目录与原文件链接 | 二维码生成、首方 JSONP 交换格式 | 扫码确认、目录、签名/链接、三种格式读取 |
| 夸克 | 首方扫码、票据换会话、个人盘验证、目录与链接 | 初始化、等待扫码状态、两个首方 config 路由的鉴权响应 | 扫码确认、Cookie 更新、目录、Range |
| UC | 首方扫码、票据换会话、个人盘验证、目录与链接 | 初始化、等待扫码状态、首方 config 鉴权响应 | 扫码确认、Cookie 更新、目录、Range |

自动化使用本地协议夹具及生成的书籍，覆盖了成功和失败状态、目录分页、授权失效、链接更新、加密存储、取消、原生目录选择与在线/离线边界。**这些检查不能代替真实账号和电视验收。** 没有读取用户现有网盘账户、浏览器 Cookie 或个人文件。

扫码授权流程还对照了用户授权的本地 NetVplayer 实现：阿里续期与原文件链接、百度扫码交换、夸克/UC 会话验证。网盘协议可以参考；macOS 的 Keychain、WebView、视频转码和播放实现没有作为 Android 电子书阅读能力使用。

实现依据与边界见 [阿里/百度协议记录](protocols/aliyun-baidu.md)、[夸克/UC 协议记录](protocols/quark-uc.md)、[CD2 分析](CLOUD-REFERENCE.md)及 [验证记录](VALIDATION.md)。
