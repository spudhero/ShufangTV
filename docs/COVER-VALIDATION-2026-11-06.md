# 首页与书库封面修复验收

2026-11-06，开发版 `0.4.0-alpha.3` / 版本码 7；Sony BRAVIA 4K UR2，Android 10 / API 29，1920×1080。

## 原因与修复

原生 CoverView 只按书名绘制通用文字封面。BookSession 虽然读取 EPUB / Kindle 的封面字节，却没有交给首页或书库，也没有缩略图缓存；书内插图实现并未连通书架封面。

首页大封面与书卡统一接入 CoverRepository。后台只加载可见项，同一书籍请求合并；结果只替换图片，不重建页面或抢焦点。按原比例完整显示，横版留边；无内嵌封面、TXT 或暂时读取失败时保留现有生成样式。

- EPUB 3 cover-image 优先于 EPUB 2 meta；兼容 guide 指向的 XHTML / SVG 封面页和命名封面。无标记时只检查首个 spine 页，不扫描后续正文。
- Kindle 封面直接按 PalmDB / MOBI / EXTH 记录偏移随机读取，不为书架解压整本书。
- PDF 完整渲染第一页；与当前页码、屏宽视口、缩放和滚动位置独立。
- 最大 384×576，内存 LRU 8 MiB；私有 cache/covers-v1 的 PNG 原子写入，最多 64 MiB / 256 张。系统可以清除缓存，缓存不是离线书籍。
- 源文件优先使用已有本地副本 / URI，失效且有在线来源时可重新提取。失败不落空缓存，30 秒后重新进入页面可重试。正文打开模式不受该策略影响。
- 普通位图的网络读取不再持有全局解码锁；仅 AndroidSVG 的全局资源解析器串行访问。

`core:test` 48 项、`app:testDebugUnitTest` 155 项，共 203 项通过；lint 0 错误、21 条既有警告，四 ABI APK 构建通过。新增检查涵盖 EPUB 封面优先级、guide / 编码路径、资源隔离与字节预算、Kindle 短读 / 记录边界 / 加密拒绝和未读正文不传输，以及缓存去重、冷启动、失败重试、脱离页面的回调、横版不裁剪、720p / 1080p 首页与书库的真实 EPUB 绑定、SVG 包图、慢封面与正文插图并行。

覆盖安装使用原开发证书，随后从实际首页与书库操作触发加载，逐本读取设备生成的 PNG 核对，16/16 均有真实封面；保存了首页、滚动书库和冷启动截图。冷启动时 NAS 保持在线；断源后缓存复用由受控单测验证，未把设备冷启动描述为真实断网测试。

仅加载封面后，设备 library.json 与安装前完全相同：17 条书籍记录（含原创指南）、1 条书签，正文位置和来源均未变化。仅保留原指南文件，没有新增完整离线书籍。原始书名、封面、书页和来源地址只保存在本地忽略目录，不提交公开仓库。

最终包另外抽查漫画 EPUB、PDF、AZW3、MOBI 各一本在线打开，真实画页 / 正文正常；除这 4 本正常更新 lastRead 外，最终书籍 ID、阅读位置及书签与原记录相同。验收后卸载临时测试 APK，保留正式应用和真实 SMB 来源。

最终 APK 与设备 base.apk 的 SHA-256 一致：`ba119dcced3761e9bd39935a418ffcb9b4c46334ecbb797236d0ab86a87c337d`。APK v2 签名验证通过，证书仍为 `9aeb612cabfb2d39bd0d7b40f212a562c0aee3440a9bd4b84e376f335ab6e0e0`。交付副本为忽略目录 artifacts 中的 `ShufangTV-0.4.0-alpha.3-covers-final-debug.apk`，保留旧发布物和原签名密钥。

本轮验证聚焦真实封面，不把之前版本的 16 本正文翻页验收重写为本轮全量正文结果。当前仍不支持 DRM / KFX；Sony 中文听书仍需要安装可用的系统 TTS 与中文数据，封面修复不改变该设备条件。
