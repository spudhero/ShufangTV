# 网盘选择页显示书籍

2026-11-06，`0.5.0-alpha.4` / 版本码 11。沿用原开发签名覆盖安装 Sony BRAVIA 4K UR2，保留原书库、SMB 来源及四个网盘账号。

## 原因与改动

用户当前页面处于“选择书籍文件夹”。旧实现传入 `directoriesOnly=true`，阿里请求因此包含 `type=folder`，原生列表还会再次跳过所有非目录项。同目录的 PDF 没有被请求或显示，界面只剩配套音频的子文件夹。上一轮登录、分区和目录读取成功不能证明书籍已经可见。

选择页改为读取完整条目，先显示子文件夹，再显示支持的书籍及格式 / 大小；支持 EPUB、AZW3、MOBI、AZW、PRC、TXT、PDF。分页改为“下一页内容”，空状态只描述当前页，非书籍文件不进入阅读列表。

“使用并浏览书籍”保存来源后直接进入书籍列表；选择某本书则添加或复用当前文件夹，重新核对实际列表后显示现有在线 / 离线面板。重复选择同一文件夹复用原来源，文件已移动时回到实际目录提示重新选择。列表和面板不下载正文，只有用户主动在线打开或保存本地才读取文件。

界面沿用既有 OpenDesign Cloud / Local Codex 的暗色书房、固定底部操作和遥控焦点规范；[原生设计修订](../design/CLOUD-UI-DESIGN.md)明确标注与历史浏览器稿的区别。本轮没有生成新的云端设计稿。
