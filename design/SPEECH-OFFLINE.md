- **旧设计不变。** 本文只更新语音方向：应用内离线中文为默认，Azure 官方网络朗读及系统语音为可选。旧稿中“系统没有 TTS 就无法开始朗读”的路径，仅适用于用户主动选择系统语音时；不能用于阻断本轮离线路径。

## 核心决策

1. **引擎选择与就绪状态分离。** 默认 `offline`；包缺失时仍保持离线选择，提示下载。焦点移至 Azure、保存配置、试听成功均不自动改变当前引擎。
2. **全局设置只留概要。** “朗读与语音”展示当前引擎、真实状态、管理入口。下载、音色、密钥与系统检测进入独立的语音管理页面，不把长表单塞进全局设置。
3. **管理页首屏固定状态与主操作。** 左侧引擎导航，右侧标题、滚动内容、固定操作行。720p 下主状态和下载/取消/重试/试听/保存动作始终可见，长表单在中间滚动。
4. **网络必须主动选用。** 使用 Azure 前明确告知“朗读段落将发送至 Azure，可能按用量计费”。离线、网络或系统的失败均不会自动切换引擎。
5. **阅读控制属于会话。** 暂停、上下段、语速和定时放在阅读内；全局设置不放正在播放的会话控制。进入语音管理保留阅读位置，返回时不自动朗读。

- 合成书名“书房声音使用指南”，正文包含指定试听文字。

## 离线语音包与状态

采用实机验证后的 **icefall AISHELL-3 轻量中文普通话（Apache-2.0，8 kHz）**。本次产品包的容量约定：首次下载 **30.1 MiB**、安装约 **31.2 MiB**、建议预留 **120 MiB**。容量来自固定归档与实际安装清单。模型来源见 [官方模型卡](https://huggingface.co/csukuangfj/icefall-tts-aishell3-vits-low-2024-04-06)。

| 状态 | 面向读者的状态/说明 | 主操作 | 就绪判定 |
| --- | --- | --- | --- |
| 未下载 | 首次下载后在应用内朗读，无需系统语音 | 下载中文语音 | 否 |
| 下载中 | 百分比、已下载 / 30.1 MiB；无虚构速度或剩余时间 | 取消下载 | 否 |
| 校验安装 | 正在检查并安装，完成前暂不能朗读 | 状态按钮；仍可返回 | 否 |
| 已有包待检查 | 正在检查已有语音包 | 状态按钮；仍可返回 | 否 |
| 就绪 | 语音包就绪，可在应用内离线朗读 | 试听声音；另有删除操作 | 真实完整性检查与引擎初始化通过后才是“是” |
| 下载失败 | 下载连接中断，请检查网络后重试 | 重新下载 | 否 |
| 校验失败 | 语音包检查未通过，请重新下载 | 重新下载 | 否 |
| 空间不足 | 整理本地空间，建议预留 120 MiB | 重新下载 | 否，不凭建议空间值假装已检测到空间 |
| 重启后上次未完成 | 下载/安装未完成，语音包尚不可用 | 重新下载 | 否 |
| 删除确认 | 删除后释放约 31.2 MiB，下次需重下 | 取消 / 删除语音包 | 确认后回到未下载 |

### 转换规则

```text
未下载 → 下载中 → 下载完成 → 校验安装 → 完整且可初始化 → 就绪
           │                     │
           ├─取消→未下载          └─失败→未就绪→重试
           └─失败→未就绪→重试

重启：已有完整包 → 检查中 → 检查通过才就绪
      只有未完成下载/安装 → 上次未完成 → 用户重试
删除确认 → 未下载，保留离线选择和阅读位置
```

下载达到 100% 只表示收到数据，不能直接写 `ready=true`。真实原生端在完整性校验、解包、必要资源检查以及引擎可初始化后才提交可用版本。重启不能只读取一个上次保存的“就绪”布尔值；应检查文件与版本记录，必要时重新验证。

取消下载使当前任务失效，后续旧回调不能把它推进到安装或就绪。校验失败/进程中断只清理该语音包自己的临时文件，不触碰书籍。删除正在使用的离线包需先停止朗读、失效化待合成任务，再删除包；不自动改选 Azure。

当前稿未获真实发布包地址、版本清单或校验值，因此不编造下载地址、哈希、设备性能或 Android 推理实现。接入时由原生工程提供与以上容量约定一致的受信任包及版本清单。

## Azure 官方网络语音

### 配置与选用

表单按“地区 → 中文音色 → 资源密钥 → 试听文字 → 选用/清除”排序。地区与资源密钥必须属于对应的 Azure Speech 资源；地区和语音列表遵循 [Azure 官方接入说明](https://learn.microsoft.com/zh-cn/azure/ai-services/speech-service/rest-text-to-speech)。

- 地区示例：东亚、东南亚、美国东部、西欧；这不是全部地区清单。原生端显示自身支持的地区，不把中国区与全球区端点混用。
- 音色示例：晓晓（`zh-CN-XiaoxiaoNeural`）、云希（`zh-CN-YunxiNeural`）。中文友好名称显示在 UI，内部标识不必暴露。真实可用性以地区返回的音色列表为准，参考 [官方语言与音色支持](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=tts)。
- 密钥使用遮蔽输入，不提供默认真实值，不出现在状态文字、错误、日志、导出或正文上。
- 原型“填入合成配置”位于审核工具栏，填入不可用的示例标记；正式产品不提供这个按钮。
- 表单初始不报错，保存/确定时校验必要字段。地区、密钥缺失有就近中文提示并聚焦首个错误。
- 保存配置显示“已配置 · 待试听验证”，保持原引擎选择不变。
- 试听前说明本次发送的试听文字和可能计费，确认后只做试听；不自动改选。
- “选用网络朗读”再次明确段落发送和可能计费，必须用户确认后才成为当前引擎。
- 配置变更使旧验证结果失效，需要重新试听/确认。试听通过仅代表本次请求通过，不承诺网络持续可用。
- 清除配置需确认，同时清除密钥、地区、音色偏好与授权状态，取消待发请求/当前网络朗读。若 Azure 仍是当前选择，显示“尚未配置”；不自动切换其他引擎。

### 网络状态

| 状态 | 主文案 | 可用操作 |
| --- | --- | --- |
| 尚未配置 | 尚未配置 | 保存配置；表单纵向滚动 |
| 配置已保存 | 已配置 · 待试听验证 | 试听声音 / 主动选用 / 清除 |
| 验证进行中 | 正在试听验证 | 停止试听 / 返回 |
| 本次通过 | 本次试听已通过 | 再试听 / 主动选用 / 清除 |
| 试听失败 | 试听失败 · 可重试 | 重试试听 / 修改配置 / 清除 |

失败提示面向读者给出“检查地区、密钥或网络后重试”，不展示鉴权响应正文或敏感信息。正式实现可区分无网络、密钥无效、地区不匹配、音色不可用和服务暂不可用；错误后保留可修改字段与显式重试，不能静默改走任何其他服务。

原型只用配置存在与否的标记，不持有真实凭据，不使用 localStorage。Android 端需要使用适合设备的安全存储方式保护用户配置；遮蔽输入只是视觉处理，不能代替存储保护。任何未主动选用网络的离线路径都不发送正文；下载模型也不上传正文。

## 系统语音：独立可选项

| 状态 | 文案 | 行为 |
| --- | --- | --- |
| 无服务 | 未检测到系统语音引擎 | 重新检测、系统语音设置；说明离线仍可使用 |
| 检测中 | 正在检测服务 | 等待，仍可返回 |
| 检测到服务 | 开启时检查中文支持 | 初始化并检查中文，不能直接声称能发声 |
| 中文检查中 | 正在检查中文支持 | 可停止检查/试听 |
| 初始化或中文失败 | 中文语音尚不可用 | 重新检查、系统设置、手动选回离线 |
| 本次通过 | 本次中文检查已通过 | 试听与主动选用；实际发声以执行结果为准 |

服务列表检测与 TTS 实例初始化分开处理。初始化回调成功后，再验证中文支持和所选语音；不能仅凭服务存在或方法调用已受理就宣布正在发声。Android 的初始化回调和语言支持检查见 [TextToSpeech 官方说明](https://developer.android.com/reference/android/speech/tts/TextToSpeech)。

系统设置没有可处理入口时，给出“未能打开系统语音设置，可在电视设置中检查语音服务”，返回当前管理页，不阻止离线下载或朗读。网页只展示此状态，不操作本机设置。

## 短句合成、播放与前台规则

实际音频由 Android 原生实现；本页没有浏览器离线 TTS、系统 `speechSynthesis` 或真实 Azure 合成。

原生建议把已选文本引擎接到同一阅读会话控制层：

1. 以当前阅读段落为边界，根据中文句号、问号、叹号等拆短句；超长无标点文本再按实现的长度上限细分。不要一次把全书交给合成器。
2. 离线逐短句合成并顺序播放，可在前台小幅预备下一句；取消/跳段时使旧任务失效，避免旧音频插回队列。不要把“短句切分”等实现细节显示在 UI。
3. 播放层驱动当前句/段高亮；收到真实准备、开始、完成、失败结果后更新状态，不用计时器猜测原生是否可发声。
4. 上一段/下一段保留速度与定时。暂停时跳段仍保持暂停，用户继续后从新段开始。语速选择 0.75 / 1 / 1.25 / 1.5 / 2 倍。
5. 定时为 15 / 30 / 60 分钟或本章末尾；以实际会话计时，切换定时重新计时；本章结束停止，不自动越章。UI 使用“定时停止”，不展示线程/队列等内部术语。
6. 暂停、结束、换引擎、删除语音包、清除网络配置都应取消已失效的准备任务；旧异步回调不能恢复播放。
7. 仅应用在前台时持续朗读。进入后台立即停止/暂停输出并取消尚未发送的网络正文，保存当前位置。返回前台保持暂停，不自动继续发声或重新发请求。
8. 从阅读打开管理时保存 `{书籍身份、章、段、句、页、滚动位置}` 的原生对应值；在管理中准备完成、失败或换引擎后，返回同一位置和原入口焦点，等待主动开始。

网页用短时计时器展示准备、逐句高亮和结束；这是明确标识的无声演示，不是设备真实速度、音频回调或延迟测量。

## D-pad、焦点与返回

- 左栏上下移动焦点，确定后切换配置页，**不会同时选用引擎**；向右进入当前页主动作。
- 右侧长表单上下按逻辑顺序到达状态、地区、音色、密钥、试听、选用、清除和底部操作。聚焦下方字段时，滚动内容区使字段完整可见；左键从普通字段回当前引擎导航。密钥输入中左右键仍用于光标。
- 引擎“选为当前”是显式操作；琥珀勾选保留在已选引擎，焦点另用浅色 2dp 轮廓 + 填充。
- 输入保持可见标签。确定键提交配置，返回退出当前选择/表单层级；使用遥控器输入法时，先尊重原生 IME 的关闭处理。
- 模态层只允许内部焦点，出现时焦点优先放“取消”；选择列表放当前选项。长说明可聚焦并上下滚动。Escape / 原生返回关闭最上层，恢复原入口。
- 删除完成后原删除按钮不存在，焦点回到“下载中文语音”；清除完成回到“保存配置”。异步下载状态变更维持同一主动作标识，取消变为下载时不丢焦点。
- 管理从设置进入：返回“朗读与语音”概要；从阅读进入：返回同一位置的阅读菜单朗读项。未就绪弹窗取消回原朗读项。
- 开放中的阅读工具限制焦点范围，关闭回正文或当前暂停/继续按钮。后台回前台不自动开始。

## 审核方式与验证范围

建议用顶部工具直接查看未下载、下载 40%、校验安装、就绪、下载失败、校验失败、空间不足、上次未完成、重启检查；这些“冻结样例”不会自行伪装成完成。正常“下载中文语音”会依次演示进度与校验；取消后回未下载。删除必须先用“就绪”或完成下载后打开确认。
