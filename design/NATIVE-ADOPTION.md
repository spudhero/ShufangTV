# 本轮设计的原生落地

2026-11-06，`0.4.0-alpha.2` / 版本码 6。设计入口为 [局部 UI 预览](ui-review.html)，OpenDesign Cloud / Local Codex 的原始交付见 [UI-REFINEMENTS](UI-REFINEMENTS.md)。本文件记录最终 Android 行为；原始规格里的建议不等同于已实现功能。

| 设计目标 | 最终原生实现 |
| --- | --- |
| 首页长书名不遮挡作者和操作 | 1080p 30sp、紧凑屏 24sp，自然高度、最多两行末尾省略；作者单行；增加完整书名详情，并保留原始数据与无障碍说明 |
| 语音准备状态优先可见 | 设置滚动内容顶部显示服务检测结果；无引擎时初始焦点为系统语音设置；返回系统后仅在服务存在状态变化时重建并恢复焦点 |
| 服务存在与中文可用分别表达 | `SpeechSetup` 只查询服务；`ReaderSpeech` 初始化时继续检查中文支持。未确认前不进入播放成功状态，不自动安装、下载或发声 |
| 沿用现有操作体系 | 保留原生五项文字侧栏、既有焦点边框、滚动和 ReadingDialog。网页新增的侧栏图形与“重新检测”演示按钮不进入 APK；重新进入设置或从系统返回会重新检查 |
| PDF 菜单符合内容能力 | 只有阅读亮度，不提供不能改变 PDF 页面的纸色；文字排版入口仍按现有格式条件控制。亮度沿用全局窗口亮度，网页仅模拟正文区域的明暗 |
| 图片和 PDF 的方向键说明准确 | 图片整图 / 屏宽可切换，屏宽图片上下滚动；PDF 100% 为适合屏宽，上下滚动至边缘可继续翻页；100% 时左右翻页，放大后左右平移，菜单和底部操作区仍可翻页 |
| 返回键语义与已有阅读器一致 | 返回键先收起工具，再退出阅读；不新增“返回退出平移”状态，已有 PDF 缩放与位置继续保存 |
| 图文混排保留文本能力 | 网页“纯图片”样例隐藏文本工具。原生 EPUB / Kindle 可能混合图片和文字，继续保留可用的正文文本功能；不做 OCR，PDF 不提供正文朗读 |

## 启动器资源

保留原始 `drawable/ic_book.xml` 的书本路径。前景、背景分离为 108dp；重要图形置于 66dp 安全圆内。Manifest 指向 `mipmap/ic_launcher`，应用最低 API 为 26，因此基础 `mipmap-anydpi/` 即可承载 adaptive icon，另提供 monochrome 层。

横幅沿用原横幅图形，加入“书房 TV”。源 PNG 为 320×180 / 640×360，原生使用 mdpi / hdpi / xhdpi / xxhdpi / xxxhdpi 五档，避免依赖系统任意放大。原始图标和横幅的书本形状略有差异，本轮分别保留原图形；安全区虚线不进入 APK。

## 预览复核后的修订

- 修正主按钮焦点样式优先级，避免通用按钮背景覆盖浅色焦点底后降低对比度。
- 720p 侧栏缩紧内边距与图形尺寸，四字菜单保持一行；合成指南封面标题保持单列。
- PDF 样例移除字体与纸色，改为阅读亮度；帮助和页脚按最终方向键语义说明。
- 画布外的语音样例仅用于布局检查，不调用系统 TTS，也不证明设备具备中文语音。原生效果、真实设备状态与测试边界见 [本轮验收](../docs/UI-AUDIT-2026-11-06.md)。

## 4K 显示增量

[原始设计](DISPLAY-4K.md)由 OpenDesign Cloud / Local Codex 生成。原生 `DisplayPanel` 沿用状态区、两种模式、折叠详情、可滚动内容和固定返回按钮；用独立原生对话框复用设置与阅读入口，后者纳入阅读弹窗计数，避免自动翻页在设置中继续。

- 原稿“高清阅读 4K”改为“4K 内容绘制”：Sony 的源缓冲区通过 UHD 像素检查，但 SurfaceFlinger / HWC 最终仍按 1080p 合成，不能把首帧提交当作面板逐像素输出证明。
- 文字阅读区随原有页眉、章节、控制栏保留实际区域，Sony 为 3456×1468；PDF 才是全屏 3840×2160。详情显示实际尺寸。
- 已有原生 4K 系统使用普通 View / Canvas，标为“系统原生 4K”，不重复创建放大 Surface。4K 布局在 Robolectric 验证，不能冒充 Sony 4K UI 实测。
- PDF 保留原有视口渲染与 100% 屏宽语义；网页里的缩放内容仅作交互示例。没有加入审核工具、设备模拟器或虚假 4K 开关。
- 未打开书籍时等待实际确认；切换兼容模式后恢复普通阅读。请求和结果分离，Surface 销毁后清除确认，失败显示回退并可重新尝试。
- 不通过 alpha=0 隐藏正文输入 View，只跳过重复绘制，以保留焦点和无障碍节点。字号仍使用 sp，界面布局使用 dp。修正首页最近阅读标题与阅读进度栏的固定像素高度。

具体设备证据与限制见 [4K 验证](../docs/DISPLAY-4K-2026-11-06.md)。
