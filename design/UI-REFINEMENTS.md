# 书房 TV · 局部界面细化

> 本文保留 OpenDesign Cloud / Local Codex 生成时的原始建议。原生接入及浏览器复核后的行为修正，以 [NATIVE-ADOPTION](NATIVE-ADOPTION.md) 为准。

## 本轮交付与边界

- 入口：`ui-review.html`，直接在浏览器中打开。画布外可切换首页、朗读与语音、阅读菜单、启动器资产，以及两种分辨率、语音能力样例、文本/PDF/图片类型。
- 样式与交互：`assets/ui-refinements/ui-review.css`、`ui-review.js`。继续引用现有 `css/tokens.css`，原页面和原样式不变。
- 所有新增书名、作者与正文均为合成使用指南，不读取本地书库、账户或真实文件。状态仅保存在页面内存中。
- 只参考本设计项目文件及 `references/ui-audit-synthetic/` 中三张截图、`ic_book.xml`、`tv_banner.png`。三张合成截图已实际打开。未访问 `private-analysis`、外部 Android 源码、真实书籍或账户数据，未执行 Git。
- 本轮只优化已确认问题。原首页、云盘、完整阅读体验交付均保留。

## 层级与页面

### 首页

沿用“侧栏 → 继续阅读 → 最近阅读”的既有结构。继续阅读改为封面与信息两列，阅读位置放在书名和作者下方，不再挤在标题侧面。

1. 页面标题“接着，读下去。”
2. 继续阅读：两行书名、作者、章名、已保存位置。
3. 一个琥珀主操作“继续阅读”；次操作“书名详情”展示完整名称。
4. 最近阅读仅使用合成使用指南，展示格式与来源，不虚构阅读百分比。

长标题规格：1080p 为 **30sp / 39sp 行高，最多 2 行**，两行文字自然占约 78dp；720p 为 **24sp / 31.2sp 行高，最多 2 行**。不得继续使用 48dp 固定高度，不固定整组信息高度。标题单独占一行布局，下面的作者、位置、按钮依次参与正常测量。

原生建议：标题 `TextView` 使用 `wrap_content`、`maxLines=2`、`ellipsize=END`，完整原始字符串保留在文本模型及 `contentDescription`，不要先裁切字符串。若现有布局依赖 `includeFontPadding`，保留字体上下余量并按真实字体测量；这里的 78dp 是两行基线节奏，不是强制裁剪框。作者 14sp，间距 8dp；按钮上方 8dp，作者/位置信息不得绝对定位在标题上。

### 设置：朗读与语音

放在设置内容顶部，随后仍是全局阅读默认与阅读帮助。状态说明与操作分层，只有“系统语音设置”作为该块的主要入口，“重新检测”为次操作。

| 能力状态 | 设置区文案 | 阅读菜单文案 | 可执行行为 |
| --- | --- | --- | --- |
| 未检测到服务，目标 Sony 默认 | 未检测到语音引擎 | 未检测到语音引擎 | 系统语音设置、重新检测；不承诺朗读 |
| 检测到服务，中文未检查 | 检测到语音引擎；开启朗读时检查中文支持 | 开启朗读时检查中文支持 | 开启时先检查中文支持与初始化结果 |
| 中文检查失败或尚未就绪 | 中文语音尚未就绪，请在系统语音设置确认后重试 | 保留能力提示 | 系统语音设置、重试；不进入朗读成功状态 |
| 朗读已实际初始化并可用 | 由真实执行结果决定，不仅依赖服务列表 | 显示实际暂停/控制状态 | 暂停继续、上下段、语速、定时、结束 |

禁止仅凭“有 TTS 服务”显示“中文语音可用”“可以朗读”“已能发声”等结论。浏览器没有调用 TTS，“已有朗读控件”是画布外明确标识的无声布局样例，不是 Sony 能力检测结果。

“系统语音设置”原生端尝试系统文字转语音设置入口，并处理没有匹配 Activity 的情况；使用面向读者的“未能打开系统语音设置，请在电视设置中检查语音服务”提示。不同电视菜单位置不同，不写死 Sony 设置层级。回到应用后重新检测服务；检测本身不自动开始朗读。

### 阅读菜单与控制

保留原有三组：**阅读**（目录/页码、自动翻页、正文搜索、朗读），**记录**（位置书签、段落收藏），**显示**（字体排版、亮度纸色）。保持正文在左、工具在右，右侧工具独立滚动，焦点限制在当前面板。

- 朗读项副文案直接表达能力，不再使用“中文语音·可定时”。
- 无引擎时，进入后是简短说明、系统语音设置和前往“朗读与语音”；不展示伪成功播放器。
- 已检测服务时，展示“检查并开启朗读”；本预览模拟中文检查未就绪。
- 无声控制样例保留暂停/继续、上一段、下一段、0.75/1/1.25/1.5/2 倍及 15/30/60 分钟、本章末尾、结束。
- 工具收起后，已有朗读控件集中在正文底部一条控制栏，不额外叠加多个悬浮播放器。
- 进入后台暂停；返回后保持暂停，必须由用户主动继续。
- EPUB/TXT 显示文本入口；PDF/纯图片隐藏正文搜索、段落收藏与朗读，不执行 OCR。原来的页码/外观/位置记录等功能不受本轮改动影响。

原型中的目录、搜索、自动翻页、外观、段落保存只提供合成内容的局部交互，不替代已有 `reading-features.html` 的完整功能规格。侧栏的书库、书签指向既有阅读体验入口，来源指向既有云盘设计入口；这些页面未被改写。

### 阅读帮助

帮助为设置里的可滚动内容，分为文字、图片、PDF、朗读四块。每块可用方向键聚焦并带入视区；不要改成不可滚动的系统 AlertDialog。

- 图片“整图”：保留完整画面。
- 图片“屏宽”：按屏幕宽度显示，上下滚动长图、左右切图。
- PDF“100%”：适合屏宽，不是原纸张实际尺寸。
- PDF 常规模式：上下滚动当前页，左右翻页。
- PDF 放大后：进入平移，方向键查看四周，返回键退出平移；退出后恢复翻页语义。
- 朗读：适用于 EPUB/TXT 正文，前台使用；PDF 和图片不会自动识别文字。

## 焦点、选中与返回

- **焦点**：2dp 浅色实线，外偏移 3dp；同时填充 `#3b4235`，文字保持暖白。主操作聚焦时使用浅琥珀填充和深色文字。轮廓不改变测量尺寸，列表边缘预留 6dp，避免裁切。
- **选中**：1dp 琥珀边线、琥珀文字、勾选标记，填充 `#2d332a`。聚焦一个未选项时，原选项仍保留勾选；不要把“焦点移到此处”当作“已应用”。
- **方向键**：按可见控件的位置移动；列表可向下滚动，聚焦后将完整控件带入视区。长帮助块作为可聚焦内容块。
- **确定**：触发当前操作。正文聚焦时打开工具；自动翻页激活时切换暂停。
- **返回**：书名详情 → 原“书名详情”按钮；子工具 → 原工具项；工具 → 原正文/工具入口；从阅读进入的语音设置 → 原朗读面板；首页返回 → 首页侧栏。关闭面板恢复原入口的可见焦点。
- 保留浏览器 Tab 支持。弹层与工具限制内部焦点；画布外的预览控制不属于 Android 产品界面。
- 入场 180ms、ease-out；系统减少动态效果时取消动画。禁止靠 hover 表达核心状态。

### adaptive icon 原生落地

- 背景层与前景层的逻辑画布均为 **108×108dp**。背景 `#191C1B` 铺满，不把圆角烘焙进资源。
- 关键形状落在居中的 **66dp 直径安全圆**内，圆心 (54,54)，边界 (21,21)–(87,87)。外圈供启动器遮罩和动态效果使用，不能放品牌文字。
- 原 48×48 图标的书本路径逐字保留，去掉前景中的背景矩形。将原 48dp 坐标框整体等比放大到 **64×64dp**，偏移 (22,22)。有效书本轮廓与描边位于安全圆内。
- 原始描边为 48 坐标下 2 单位，等比变换后约 2.67dp。不开新洞、不改变书页曲线、不增加字母或新图形。
- 原平台图标仍可保留现有 `ic_book.xml` 作为旧版本兼容资源；adaptive 资源仅交付于设计工作区，尚未安装到 Android 仓库。
- 将交付的 `android/` 子目录映射到应用 `res/` 的同名资源目录，再由应用实际资源名接入 Manifest。电视横幅与 launcher icon 分别引用，不将 16:9 横幅当作 adaptive icon。
- 画布内圆形、圆角方形遮罩及安全圆仅用于设计说明；虚线不会出现在交付的 PNG、SVG 前景或 Android XML 中。

素材来源均为用户指定的本地原创资产，没有外部图库、生成图或第三方字体包。本次工作区媒体指引接口未返回可读内容，故保留上述本地原图派生方式，未使用外部素材服务。

## 原生接入建议

以下是接入职责建议，不表示本轮读写了外部原生源码，也不假定现有方法名。

1. **首页 View / `MainActivity.java` 对应的首页绑定处**：按“标题 → 作者 → 位置 → 操作”竖向测量，移除标题固定 48dp 高度；建立完整书名详情与可访问性描述。
2. **设置页面 / `MainActivity.java` 设置入口**：把“朗读与语音”作为持久能力信息区加入滚动内容。服务检测、系统设置跳转、返回后刷新与“开启朗读时检查中文”分开处理。
3. **`ReaderScreen.java` 对应阅读菜单处**：继续沿用阅读/记录/显示分组；朗读副文案来自能力状态；EPUB/TXT 与 PDF/图片使用格式能力约束，避免渲染不可用文本入口。
4. **`ReaderScreen.java` 对应朗读控制处**：仅在真实初始化及中文支持检查通过后进入实际控制状态；保留暂停、上下段、语速、定时。生命周期暂停后不自动恢复发声。
5. **`TvStyle.java` / 公共焦点背景**：复用现有色彩，统一 2dp 外轮廓和填充，区分 checked/selected 与 focused；为滚动容器的焦点留外侧空间。
6. **资源与帮助**：应用分辨率相关尺寸可放资源维度分组；帮助放可滚动容器；把电视横幅、adaptive 两层及旧图标分别挂接。

## 预览限制

本稿提供内存交互，不调用真实 TTS、系统设置、网络、OCR，也不写入书签或书库文件。PDF/图片类型用于检查工具可用范围与帮助文案，不承担真实文件渲染。书库/来源/收藏的完整交互继续参考原交付。本轮未新增浏览器截图、播放或正式原生验收流程。
